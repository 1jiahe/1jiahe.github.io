# Resume Website

This is a no-build static resume website, ready to publish with GitHub Pages.

## Publish with GitHub Pages

1. Create a GitHub repository (for example, `resume`) and upload these three files to its root directory.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**. Choose the `main` branch and `/ (root)`, then save.
4. GitHub will show the website address after a short wait.

## Personalize it

In `index.html`, replace `Zhang Chen`, `hello@example.com`, `your-github`, company names, and project copy with your own information. All content lives in this single file.
